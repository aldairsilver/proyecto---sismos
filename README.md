# Catálogo Sísmico del Perú (1960-2025)

Proyecto de Programación Avanzada 2026-II (UPCH).
Página web interactiva en Streamlit que analiza el catálogo sísmico del
Instituto Geofísico del Perú (IGP) según magnitud, profundidad y ubicación.

## Contenido
- `app.py`: código de la página web
- `data/`: catálogo sísmico (CSV)
- `imagenes/`: imágenes usadas en la página

## Cómo ejecutarlo
pip install -r requirements.txt
streamlit run app.py
